# 実験・調査・過去レポート (`reports/`)

各機能・モデル開発・移植フェーズ・Web 検証において作成されたレポートや調査記録を格納するディレクトリです。記載・分類ルールは [docs/documentation-guide.md](../docs/documentation-guide.md) を参照してください。

## ディレクトリ構成

- **`models/`**（[索引](models/README.md)）: ZeroCon Model（Nano v2〜v4.1 / Standard / Origin 等）の学習・量子化・推論速度・精度比較レポート
- **`typo-assist/`**（[索引](typo-assist/README.md)）: タイポ補正、キーボードハイブリッド、先読み、翻訳入力の検証・評価レポート
- **`port-history/`**（[索引](port-history/README.md)）: Windows 版から Android 版への移植過程におけるステージ別進捗記録（stage2〜10）や監査・復旧記録
- **`web/`**（[索引](web/README.md)）: ブラウザ体験版（Wasm）のパリティ検証記録および比較・紹介 HTML 成果物
