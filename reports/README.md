# 実験・調査・過去レポート (`reports/`)

各機能・モデル開発や移植フェーズにおいて作成されたレポートや調査記録を格納するディレクトリです。

## ディレクトリ構成

- **`models/`**: ZeroCon Model（nano, standard, v2〜v4等）の学習・量子化・推論速度・精度比較レポート
- **`typo-assist/`**: タイポ補正、キーボードハイブリッド、二段先読み等のアルゴリズム検証・評価レポート
- **`port-history/`**: Windows版からAndroid版への移植過程におけるステージ別進捗記録（stage2〜10）や監査記録
- **`web/`**: 比較・紹介用のHTML成果物
