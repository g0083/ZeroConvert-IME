# Android移植進捗・監査記録 (`reports/port-history/`)

Windows版 azooKey から Android版 ZeroConvert-IME への移植過程で作成された、各ステージの作業記録および監査レポート群です。

## 主な記録

- `android-windows-port-progress.md`: 移植全体の進捗サマリー
- `android-port-completion-audit.md`: 75項目の移植完了監査記録
- `android-windows-port-stage2.md` 〜 `stage10.md`: 各ステージの詳細作業記録
- `windows-android-conversion-comparison.md`: 変換ロジックの比較
- `windows-android-feature-gap.md`: 移植初期の機能ギャップ一覧
- `windows-source-recovery.md`: ソースコードの巻き戻り復旧記録
- `android-shared-engine-validation.md`: 共通エンジンの検証記録
- `windows-shared-performance-validation.md`: 共通エンジン適用時の性能検証記録
