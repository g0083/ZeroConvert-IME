# Androidのクリップボード候補表示（2.0.7-dev）

2026-10-26、候補欄のクリップボード提案を追加から一定時間だけに制限した。
ピン留めした項目は、追加直後でも候補欄には出さない。クリップボードパネルの履歴・
ピン留め・貼り付けは引き続き利用できる。

## 表示ルールと設定

- 既定は追加から3分。設定画面の「クリップボード設定 → 候補欄への表示時間」で、
  表示しない / 1 / 2 / 3 / 5 / 10 / 15 / 30分を選べる。
- 非ピン留めで期限内の項目のうち、追加時刻が最も新しいものを表示する。
- 入力せずに待っていても期限で消える。設定変更とピン留め変更は即時反映する。
- テキストと画像に同じ条件を適用する。候補表示の期限では履歴を削除しない。
- 編集やピン解除で追加時刻を更新せず、古い内容の表示期限を延長しない。
- 変換候補や選択文字数があるとき、および貼り付けて提案を閉じたあとには表示しない。

キーは `clipboard_suggestion_minutes`、int、既定3、0で無効、上限30。
`ClipboardSuggestionPolicy`で条件を定義し、`rememberClipboardSuggestion`は
次の失効時刻にコルーチンで待機して表示を更新する。打鍵ごとのタイマーやI/Oは追加しない。
MainActivityの保存とIMEの設定リスナーは同じキー・既定値・範囲を使う。
履歴の保持時間設定とは別で、Windows共通エンジンへの設定受渡しは不要。
