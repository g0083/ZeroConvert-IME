# Windows 翻訳入力（試験機能）

## 操作

設定画面の「翻訳機能を有効にする」をONにして、モデル（既定0.8B、任意2B）を選ぶ。設定ONだけでは通常入力を翻訳しない。

- 文字未選択で **Ctrl+T**: 翻訳モード開始。入力先にフォーカスを残し、日本語を通常のローマ字入力で編集する。
- 打鍵休止400ms後に非同期翻訳を要求する。訳文が届くと、次のキーを待たずに入力先の**未確定文字列**を英訳全文へ置換する。翻訳はトークン単位のストリーミングではなく、現在の文の訳が完成するごとの更新。
- **Enter / Tab**: 現在の英文を確定してモード終了。翻訳待ち・失敗時は日本語を誤確定しないようキーを消費する。入力し直すかEscで取り消す。
- **Esc / 再度Ctrl+T**: 未確定の追加分を取り消して終了。既に確定した文章は残す。
- アプリ・入力欄のフォーカス変更でもモードを終了し、古い非同期結果を破棄する。
- 文字選択中のCtrl+T / 「翻訳」ボタンは選択翻訳。入力先の文字を置換せず、結果ポップアップへ表示する。

翻訳バーは原文・訳文・モデルを表示し、入力先をアクティブなまま保つ。翻訳中の日本語編集・読み・候補IDと、入力先に表示した英訳は別の役割として保持する。英訳をかな漢字変換の学習候補にはしない。

## 実行場所と連続入力

翻訳はメイン変換と同じ `zenzai.backend`（CPU / CUDA / Vulkan）と実効GPU層数の設定を使うが、専用の `llama-server.exe`（ポート18092）に別のPLaMoモデルを読み込む。メイン変換モデルと同じプロセス・重みを共有するわけではない。

最後の打鍵から400ms休止すると翻訳を要求する。文章が完結したかどうかの判定ではない。追加入力で待機中のクライアントタスクを中止し、最新の入力に対して待ち直す。モデルは `--parallel 1`、変換サーバー側の翻訳枠も1件。開始済みの古い推論はクライアントの取消だけでは最後まで計算される場合があるが、古い結果を現在の入力へ反映しない。要求が常に即時停止し、待ち行列が必ず空になるという保証はしない。

詳細設定→「翻訳モード・選択文字翻訳」に **「翻訳サーバーを常時起動する」** を追加。

- OFF（既定、`general.translation_keep_alive = false`）: 翻訳セッション中だけ起動し、終了すると解放。
- ON: 翻訳機能がONの間はモードを閉じてもサーバー・モデルを保持。IMEランチャー起動時にも準備する。RAM/VRAMを継続使用する。
- 翻訳機能そのものをOFF: 常時起動設定に関わらず、ランチャーが所有する翻訳サーバーを停止。

設定変更はランチャーの監視周期（約2秒）で反映する。モデルや実行ファイルが未配置の場合は起動しない。手動で起動した外部サーバーは勝手に停止しない。

## 起動・適用

翻訳セッションの所有数をWindowsの名前付きセマフォで管理し、ランチャーが所有者のいる間だけポート18092の翻訳モデルを起動する。複数の翻訳表示が重なっても、一方の終了で他方のサーバーを止めない。モデル準備はバックグラウンドの `/health` 応答で確認する。準備前は「モデルを読み込み中」と表示し、最大30秒待ってから翻訳要求（最大10秒）へ進む。入力コールバックは待機しない。

通常の更新はルートの `Build-Trial.bat -NoPause`。自動適用後、入力アプリを開き直す。既存アプリは旧TSF DLLを保持し得る。翻訳機能の設定、モデル取得と起動経路は `windows/crates/shared/src/runtime_assets.rs`、`windows/crates/launcher/src/main.rs`、`windows/scripts/start-translation-server.ps1` を参照。

## 実装箇所

- `windows/crates/client/src/tsf/key_event_sink.rs`: Ctrl+T / Esc、英文確定後のモード終了。
- `windows/crates/client/src/engine/state.rs`: 通常入力と翻訳モードで設定スナップショットを切替。毎キーで全設定をコピーしない。
- `windows/crates/client/src/engine/composition/typo.rs`: スナップショット照合、結果到着時のTSF更新、セッション管理。
- `windows/crates/client/src/engine/composition.rs`: Enter/Tab、翻訳バー用UI更新。
- `windows/crates/ui/src/main.rs`、`translation_bar.rs`、`translation_bar.html`: 入力先からフォーカスを奪わないバー。
- `windows/crates/client/src/tsf/selection_count.rs`: 選択翻訳のTSF通知と有界コマンド送信。`selection_popup.rs` の専用UIスレッドがウィンドウ・描画を所有し、別の通信スレッドから世代付き結果を受け取る。入力アプリのTSFスレッドで翻訳ポップアップを作成・更新しない。
